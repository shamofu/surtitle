## Evidence limits

The c geometry run and final d installed run are separate identities; physical high-DPI checks must not be relabeled as reruns of final d. Both monitors were restored to their original 100% settings. Browser fixtures do not prove native performance, and the bounded codec trials do not establish all-GPU reliability or perceptual A/V synchronization. Installed missed-event fault injection and Linux CI execution were not measured in this acceptance; protocol/browser recovery and Windows lifecycle were. No public release or replacement of the user's installed application/profile was performed.
